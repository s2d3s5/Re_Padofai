# Re_Padofai
A Godot project replicating *A Dance of Fire and Ice (ADOFAI)*

## 项目介绍
基于 Godot 引擎自制复刻《冰与火之舞》，还原核心双球跟随轨道游玩机制

## 特点
1. 支持导入.adofai文件，以及背景音乐
2. 全轨道显示（以轨道分区实现）（多Polygon2D复用）
3. 运行内存占用较低、导入速度适中
4. 显卡占用低，仅限兼容模式
5. 没那么容易崩溃

## 运行方式
1. 下载完整源码
2. 使用 Godot4.7stable_mono 引擎打开项目工程文件即可运行测试
